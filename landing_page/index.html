01 / NAME

dock
vim

TUI minimalista de panel único para administrar contenedores Docker y proyectos Docker Compose. Escrita en Go. Usa la CLI docker, no el SDK.

02 / SYNOPSIS

Una lista. Un teclado.

Contenedores y proyectos Compose en un solo panel. Navegas como en vim, confirmas lo destructivo y vuelves a la lista.

Los puertos se muestran compactos: 8000→80. Si no están publicados, aparece —.

03 / KEYS

Teclas

j kNavegar (también flechas)
g GPrimer / último elemento
TabContenedores ⇄ Compose
/Buscar por nombre · Enter confirma · Esc cancela
lLogs en vivo del contenedor
esh interactivo dentro del contenedor
sIniciar contenedor
xDetener · pide confirmación
rReiniciar · pide confirmación
ucompose up -d · confirma
dcompose down · confirma
RActualizar lista
qSalir
Pasa el cursor por una tecla. Todo lo que elimina o reinicia algo pregunta antes.

04 / COMPOSE

Proyectos agrupados por etiqueta.

dockvim agrupa con la etiqueta de Compose y, para up y down, lee además el directorio de trabajo y los archivos de configuración.

com.docker.compose.project
  agrupa los proyectos
com.docker.compose.project.working_dir
  desde dónde ejecutar up / down
com.docker.compose.project.config_files
  qué archivos usar
Si faltanLa acción se cancela con un error explicativo. Proyectos antiguos, recreados a mano o gestionados por Portainer pueden necesitar ajuste.

05 / NOTES

01

Sin SDK

Todo pasa por la CLI docker. Necesitas acceso al daemon: docker ps debe funcionar.

02

Sin shell

Cada argumento se pasa por separado a os/exec. Los nombres de contenedor nunca arman un comando de shell.

03

Confirmación

x, r, u y d piden confirmar. compose down elimina contenedores y redes del proyecto.

04

Al día

La lista se actualiza cada 5 segundos y con R. La búsqueda filtra lo que ya está en pantalla.

05

Vas y vuelves

docker logs -f y docker exec -it corren como procesos interactivos y devuelven el control a la TUI.

06

Aún no

Filtros por estado, temas, servicios individuales y selección múltiple. La shell usa sh, no bash.

06 / INSTALL

Compila y listo.

  • Go 1.23 o superior
  • Docker CLI
  • Acceso al daemon
  • Compose v2 (acciones Compose)
  • Terminal de 100×30 o más
# probar
$ git clone https://github.com/pablotrianda/dockvim
$ cd dockvim
$ go mod tidy
$ go run ./cmd/dockvim

# instalar
$ go build -o dockvim ./cmd/dockvim
$ sudo install -m 0755 dockvim /usr/local/bin/dockvim
